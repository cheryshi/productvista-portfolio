01 / Commerce storytelling

Advanced Product Showcase

用同步的商品主视觉与推广文案构成双栏展示，让单品选择与品牌叙事发生在同一屏。

配置方式
在区块属性中维护 slides、商品、背景、富文本、按钮和响应式数量；编辑器通过 ProductPicker 选择商品。
技术实现
PHP 动态渲染并过滤非公开或不可见商品；前台与编辑器脚本分离，共用本地 Swiper 11.0.0 和按钮组件。

02 / Shoppable imagery

Hotspot Product

在场景图上放置可交互热点，把视觉中的物品直接关联到 WooCommerce 商品卡与加购路径。

配置方式
设置背景图、热点坐标、商品 ID、选中项、图片适配以及商品与加购按钮样式。
技术实现
服务端输出首个有效商品；公开 Ajax 使用 nonce 与商品可见性检查更新卡片，并接入 WooCommerce add-to-cart。

03 / Curated variants

Color Switch

用颜色或分组切换场景图与成组商品，支持快速查看和加购，适合搭配灵感与系列陈列。

配置方式
每组维护颜色、图片和商品 ID 集合；可设置商品上限、移动端可见数量、按钮样式与动效。
技术实现
Ajax 批量查询限制在 24 项并过滤非公开/不可见商品；nonce 可刷新，前台处理快速切换、快览与加购反馈。

Under the hood

为 WordPress 的真实运行方式而设计

项目没有构建步骤，也不依赖 ACF。PHP 负责注册与动态输出，原生 JavaScript 管理交互，资源通过 WordPress handle 组合。

register_block_type()render_callbackapi_version: 2
  1. 01

    区块注册

    每个模块在 init 中注册编辑器脚本、前台样式/脚本和 Gutenberg API v2 区块；模块管理器扫描目录并只加载后台已启用项。

  2. 02

    配置与数据

    配置主要保存在 block attributes。商品选择器通过受 edit_posts 权限保护的 REST 搜索 WooCommerce 商品；代码中未发现 ACF API。

  3. 03

    动态渲染

    11 个区块均由 PHP render_callback 输出。商品模块在渲染或 Ajax 响应前检查 publish 状态与可见性，并按上下文转义。

  4. 04

    资源与维护

    公共按钮、链接工具与 Swiper 先注册后按模块声明依赖；Swiper 11.0.0 固定在插件本地。部分资源以 filemtime 做缓存版本。
